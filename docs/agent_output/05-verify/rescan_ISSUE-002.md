## 2. Reasoning

The issue reported six unauthenticated endpoints across four application services plus two open infrastructure services. The diff adds `spring-boot-starter-security` and an HTTP Basic credential to `employee-service` only (`fix_ISSUE-002.diff` touches only `src/employee-service/pom.xml`, `src/employee-service/src/main/java/.../EmployeeController.java` and `src/employee-service/src/main/resources/application.properties`).
