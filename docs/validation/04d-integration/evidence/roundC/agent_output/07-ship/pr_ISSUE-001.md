## Summary

- Moves the only module off the out-of-support platform: spring-boot-starter-parent 3.5.0 -> 4.1.1, java.version 17 -> 21, compiler source/target 17 -> <release>${java.version}</release>, and Dockerfile eclipse-temurin:17-jre -> 21-jre. 6 files change, all through one previewed OpenRewrite recipe (04D run issue-001-20261001T033403Z; see docs/agent_output/04-remediation/migration_issue-001.md).
- Changes the code the Boot 4 generation forces: JacksonConfig ported to Jackson 3 (tools.jackson JsonMapper.builder with NON_NULL), DatabaseHealthIndicator imports moved to org.springframework.boot.health.contributor, @MockBean -> @MockitoBean, test-slice imports moved, and the Boot 4 modular test starters added. The Testcontainers 1.20.1 pins are unchanged.
- 04D Migration Status is PARTIAL PASS. One blocking condition is still open: API consumers must accept the framework-owned response changes (401 timestamp 'Z', WWW-Authenticate charset, ProblemDetail without 'type', and new health components/groups).

These two failures were already present on the 3.5.0 baseline. The behavior guard reported BEHAVIOR_CHANGED, with 8 out-of-scope observable changes. Among them: unknown JSON request properties are now accepted instead of returning 400, trailing tokens are now rejected, the H2 console is no longer served, and Spring MVC no longer uses the app's JacksonConfig bean.
