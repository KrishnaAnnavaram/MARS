## 3. Why this is the smallest correct diff

Replace both unbounded MongoRepository.findAll() calls with the catalog's CWE-770 canonical approach: a paginated Spring Data read (Pageable / Page<T>) with a server-enforced maximum page size. The scheduler and report paths both walk every record by design, so each iterates pages rather than materialising one list. This closes the root cause — an allocation whose size is controlled by collection growth rather than by the application — instead of only making today's dataset fit.

**Catalog pattern (`CWE-770`):** Allocation of Resources Without Limits or Throttling
