## 3. Why this is the smallest correct diff

Replace the string-concatenated BasicQuery with a parameterised Criteria query, following the catalog's CWE-943 canonical approach adapted to this repository's Spring Data MongoDB stack. Binding name and department as Criteria values — with Pattern.quote on the regex path — removes the caller's ability to inject query structure, which closes the mechanism rather than the specific payload quoted in the issue.

**Catalog pattern (`CWE-943`):** Improper Neutralization of Special Elements in Data Query Logic (NoSQL/SQL Injection)
