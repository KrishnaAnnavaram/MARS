## 1. What the new test proves

Asserts getAllEmployees() issues a bounded, page-limited repository read rather than an unbounded findAll(). The captured Pageable must carry a page size of at most 500, which is the server-side cap the fix introduced. Against the pre-patch code — a no-argument findAll() — the paged overload is never called and the assertion fails, so the test genuinely distinguishes fixed from unfixed.

**Mocking strategy:** Mockito-mocks EmployeeSchedulerRepository and captures the Pageable passed to findAll(Pageable) with an ArgumentCaptor, returning a stub PageImpl. No Spring context and no MongoDB are involved, so it runs in this sandbox.
