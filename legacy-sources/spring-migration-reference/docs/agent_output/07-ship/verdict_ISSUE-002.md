## 3. Narrative

Blocked with two independent hard gates, and this one should not ship in anything like its current form. The re-scanner found the originally reported finding still triggers: only employee-service received the security starter, so report-service still serves the full payroll spreadsheet, sheduler-service still serves every employee record, and department-service still serves salary bands — all to an anonymous caller. The red-team confirmed the practical consequence: the attacker simply asks a different service, which is exactly the anti-pattern the CWE-306 catalog entry warns about. The patch also introduces a new weakness, a static HTTP Basic credential whose default password is committed in application.properties, trading a missing-authentication finding for a hardcoded-credential one. The behavior-guard additionally notes the change is both wider than the plan in one place and narrower in five others. The log-exposure half is genuinely improved and worth keeping. The correct next step is to complete the filter chain across every affected service and replace the interim credential before this returns to the gate.
